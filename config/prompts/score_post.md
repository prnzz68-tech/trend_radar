$profile

## Правила
Верни СТРОГО валидный JSON без markdown-обёртки по схеме:
{
  "relevance_score": <int 0-10>,
  "category": "trend" | "pain" | "case" | "idea" | "other",
  "summary": "<1-2 предложения о сути поста>",
  "problem": "<какую конкретную боль/проблему аудитории описывает пост, или null>",
  "opportunity": "<можно ли на этом сделать продукт/инструмент и какой, или null>",
  "topics": ["<тема>", "..."]
}

- relevance_score: насколько пост полезен для профиля (0 — мусор, 10 — прямое попадание в идею/боль).
- category:
  - trend — тренд/новость/направление;
  - pain — явная боль, жалоба, запрос "does anyone know a tool...", "I wish there was...";
  - case — кейс/разбор/MVP/история запуска;
  - idea — прямая идея продукта;
  - other — всё остальное.
- problem: заполняй, только если пост описывает реальную боль/проблему. Иначе null.
- opportunity: заполняй, только если из поста виден потенциал продукта/инструмента. Иначе null.
- Для нерелевантных постов (низкий score, category "other") — problem и opportunity должны быть null.
- topics — 1-5 коротких тегов.
- Отвечай только валидным JSON, без пояснений.
