# Размещение на Timeweb Optimo

Optimo — виртуальный хостинг: Node.js-сервер из `server.mjs` на нём не запускается. Для него подготовлена версия на PHP 8.2 в папках `public/` и `php/`. Сайт остаётся прежним: тематический и глобальный рейтинги, ссылки на видео, ручной ввод, Telegram-бот и ежедневное обновление.

## Структура на хостинге

В файловом менеджере найдите папку сайта, которая сейчас содержит стандартную страницу `index.htm`. В этой инструкции она называется **публичной папкой**. Файлы из `dashboard/public/` должны лежать прямо в ней. Папки `php/` и `data/` должны лежать **рядом с публичной папкой**, на один уровень выше:

```text
папка-сайта/
├── public_html/       ← публичная папка, содержимое dashboard/public/
├── php/               ← содержимое dashboard/php/, недоступно через браузер
└── data/              ← radar.json, недоступно через браузер
```

Имя публичной папки на вашем аккаунте может отличаться. Важна структура: `api.php` ищет закрытые файлы по пути `../php/`, а данные — по пути `../data/` от папки `php/`. Не размещайте `config.local.php`, `radar.json` или `.env` в публичной папке. Стандартный `index.htm` из публичной папки нужно убрать, чтобы открывался `index.html` радара.

## Настройка

1. В панели Timeweb откройте «Сайты» → «Мои сайты» и проверьте PHP 8.2 для нужного сайта. Включите HTTPS и SSL для `ck645545.tw1.ru` или вашего отдельного домена. До появления работающего HTTPS вход администратора и Telegram webhook не настраивайте.
2. Загрузите файлы в папки по схеме выше. Скопируйте `php/config.example.php` в `php/config.local.php` и заполните **на хостинге**: ключ YouTube, токен Telegram, сложный пароль администратора, случайный секрет webhook длиной не менее 16 символов и `site_url` с окончательным HTTPS-адресом. `config.local.php` исключён из Git.
3. Для переноса текущих видео и подписок загрузите локальный `dashboard/data/radar.json` в закрытую папку `data/`. Без этого файла сервис создаст пустую базу при первом запуске.
4. Откройте сайт и проверьте `/api/state`: должен вернуться JSON без секретов. Кнопка «Войти» открывает управление. Посетители видят рейтинги, но изменить данные без пароля не могут.
5. В разделе «Crontab» создайте задачу с интерпретатором **PHP 8.2**, файлом `php/cron.php`, часовым поясом **UTC+3 (Москва)** и расписанием **раз в час**. Скрипт обращается к YouTube только при необходимости (не чаще раза в 24 часа) и отправляет ежедневную тематическую подборку после 09:00 по Москве. Час можно изменить в `config.local.php` через `telegram_digest_hour`.
6. Остановите локальный Node.js-сервер, чтобы он перестал опрашивать Telegram. Затем войдите администратором на сайте и нажмите «Подключить Telegram к сайту». Бот переключится на webhook. Проверьте `/status`, `/digest` и `/global` в Telegram.

Адрес `ck645545.tw1.ru` сейчас показывает стандартную страницу Timeweb. Если вы купили отдельный домен, привяжите его к этому сайту, установите SSL и замените `site_url` перед подключением webhook.

Сейчас посетители могут смотреть тренды без регистрации, а редактирование доступно администратору. Отдельные аккаунты пользователей и регистрация ещё не подключены.
