# Тренд радар

Локальная панель для ежедневного отбора трёх коротких видео об онлайн-обучении и курсах подготовки к ЕГЭ. На основе метрик она помогает подготовить рекламный тест.

Для тарифа Timeweb Optimo подготовлена отдельная PHP-версия. Порядок размещения: [TIMEWEB.md](TIMEWEB.md).

## Запуск

Требуется Node.js 20 или новее. Из папки проекта:

```powershell
node server.mjs
```

Откройте `http://127.0.0.1:4173`.

Для YouTube API сохраните ключ в локальном файле `.env` рядом с `server.mjs`:

```text
YOUTUBE_API_KEY=ваш_ключ
```

Также можно указать его только для текущего сеанса перед запуском:

```powershell
$env:YOUTUBE_API_KEY = 'ваш_ключ'
node server.mjs
```

Файл `.env` исключён из Git. Не загружайте его вместе с проектом на хостинг; на Timeweb Optimo ключ задаётся в закрытом файле `php/config.local.php` за пределами публичной папки.

Ключ создаётся в Google Cloud для YouTube Data API v3. Приложение ищет короткие видео по теме и региону за последние 7 дней, получает публичные просмотры, лайки и комментарии. Профиль по умолчанию «онлайн обучение и курсы ЕГЭ» ищет онлайн-курсы, онлайн-обучение и курсы подготовки к ЕГЭ; отбор по заголовкам отсеивает нерелевантные видео. При смене темы в настройках поиск использует введённую фразу. Синхронизация выполняется при запуске и далее раз в 24 часа, пока сервер работает. После остановки компьютера пропущенные дни не публикуются задним числом; новая синхронизация произойдёт при следующем запуске.

Отдельный блок «Глобальные тренды по просмотрам» собирает короткие YouTube видео за последние 7 дней по тегу формата `#shorts`, без запроса по теме и без ограничения регионом, затем сортирует их по публичным просмотрам. Ручные TikTok, Instagram и Threads за тот же период также участвуют в этом рейтинге. Это выборка доступных через API видео, а не исчерпывающий список всех роликов мира: ролики без тега могут не попасть в выборку, и YouTube может вернуть неполный результат при сортировке и фильтре по дате.

### Ограничение запросов

- Между запросами к YouTube API выдерживается минимум 1 секунда. Временные ошибки повторяются не более двух раз с растущей паузой; при ответе `Retry-After` пауза учитывается.
- Ручная кнопка «Обновить» доступна не чаще раза в 60 минут, даже если предыдущая попытка завершилась ошибкой. Время последней попытки хранится в `data/radar.json` и сохраняется после перезапуска. Ежедневное обновление работает отдельно.
- Если YouTube сообщает об исчерпании дневной квоты, запросы приостанавливаются на 24 часа. Если сервис продолжает ограничивать частоту запросов после повторов, приложение делает паузу на час или на время, указанное в `Retry-After`.
- Telegram получает сообщения через длинный опрос, отправляет сообщения с интервалом минимум 1 секунда, ограничивает повтор команд `/digest`, `/global` и `/status` до одного раза в 30 секунд и увеличивает паузу при ошибках до 5 минут. При ответе Telegram `retry_after` ждёт указанное время.

Эти ограничения уменьшают вероятность временной блокировки. Они не отменяют квоты и правила самих платформ.

Без ключа экран показывает записи-примеры без ссылок на реальные видео. Первое добавленное реальное видео отключает демо-режим. Ручной импорт доступен кнопкой «Добавить видео»; ссылка на видео обязательна и появляется в столбце «Источник». Все реальные данные хранятся локально в `data/radar.json`. Для резервной копии сохраните этот файл.

## Подключение Telegram-бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot` и следуйте его подсказкам. Имя пользователя нового бота должно оканчиваться на `bot`. Скопируйте выданный токен и никому его не отправляйте.
2. Остановите локальный сервер и добавьте в `dashboard/.env` строку `TELEGRAM_BOT_TOKEN=полученный_токен` рядом с `YOUTUBE_API_KEY`. Не добавляйте `.env` в GitHub.
3. Запустите сервер снова командой `node server.mjs` из папки `dashboard`. Откройте своего бота в Telegram и отправьте ему `/start`. Это включает ежедневную подборку. Любой другой пользователь может сделать то же самое в личном чате с ботом.
4. При желании задайте `TELEGRAM_DIGEST_HOUR=9` в `.env` — час ежедневной отправки по Москве от 0 до 23. По умолчанию — 09:00. Ранее сохранённый `TELEGRAM_CHAT_ID` автоматически переносится в список подписчиков при первом запуске новой версии; для новых пользователей он не требуется.
5. Отправьте боту `/digest`, чтобы сразу получить тематическую подборку. Команда `/global` показывает отдельный топ-3 глобальных видео по просмотрам; `/status` показывает число видео и состояние YouTube. Команда `/stop` отключает ежедневную отправку, но оставляет команды доступными. Ежедневное сообщение содержит тематический топ-3 со ссылками и гипотезу для рекламного теста.

Бот отвечает всем пользователям. Ежедневная подборка отправляется тем, кто вызвал `/start` в личном чате; подписки хранятся локально в `data/radar.json`. Он использует опрос Telegram API, поэтому публичный адрес и webhook для локальной версии не нужны. Компьютер и сервер должны работать; если сервер запускается после указанного часа, он отправит пропущенную за этот день подборку при запуске. При отсутствии реальных видео ежедневная отправка пропускается.

## Ограничения текущей версии

- TikTok, Instagram и Threads пока пополняются вручную. Для автоматического поиска публичных роликов разных авторов потребуется отдельный поставщик данных: текущий ключ YouTube не даёт доступа к этим платформам. Доступные метрики нужно сверить с выбранным источником до подключения.
- После подключения YouTube демонстрационные карточки TikTok и Instagram больше не смешиваются с реальной статистикой. В фильтрах видны счётчики по платформам и причина пустой выдачи. При ручном добавлении видео из выбранного фильтра платформа подставляется автоматически.
- Охват нельзя вычислить по просмотрам; показывается только при наличии исходной цифры.
- Поиск YouTube по короткой длительности не гарантирует, что каждый результат является Shorts. Перед запуском рекламы проверьте выбранные видео.
- Рекомендация сравнивает просмотры лидера с медианой всей подборки, его вовлечённость с медианой и наиболее вовлекающим роликом топ-3. На этой основе предлагаются два варианта креатива и равный рекламный тест. Сервис пока анализирует названия и публичные метрики, но не само видео или конверсии.
- Регистрация и аккаунты пользователей в панели оставлены для этапа размещения на хостинге. Подписки Telegram-бота работают для нескольких пользователей уже локально.

## Дальше

Для публичного запуска потребуются хостинг с постоянно работающим сервером, база данных, регистрация и безопасное хранение API-ключей. После подключения аккаунтов можно добавить разрешённые источники Meta/TikTok и индивидуальные Telegram-подписки.
